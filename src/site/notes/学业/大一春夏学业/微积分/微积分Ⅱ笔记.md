## 级数

### 级数的基本概念

#### 级数的概念

- 有限个实数相加一定是实数，但是无限个实数相加不一定是实数 
	- ----> 满足什么条件下无限个实数的和还是实数？
		- 可以用于计算函数值
- 概念
	- 数项级数 / 级数 
		- $设u_{1},u_{2},u_{3}\dots u_{n}\dots 是一个给定的数列，则\sum_{n=1}^{\infty} u_{n}为数项级数$
	- 第n项部分和 / 部分和
		- $S_{n}=u_{1}+u_{2}+u_{3}+\dots+u_{n}$
	- 收敛
		- $\lim_{ n \to \infty } S_{n}=S(常数)$
	- 发散
		- $\lim_{ n \to \infty }不存在$
- 重要级数
	- 几何级数（等比级数）
		- $\vert q \vert<1时，几何级数收敛，为\frac{a}{1-q}$
		- $\vert q \vert\geq 1时，几何级数发散$
	- p级数：$1+\frac{1}{2^{p}}+\frac{1}{3^{p}}+\dots+\frac{1}{n^p}+\dots=\sum_{n=1}^{\infty}\frac{1}{n^{p}}$
		- $p=1时为调和级数$
		- $p>1时，级数收敛$
		- $p \leq 1,级数发散$
#### 级数的基本性质

- 线性运算法则
- 有限项的变化不影响级数的敛散性
- 收敛级数的结合性（前提时级数收敛）
- $若级数\sum_{n=1}^{\infty} u_{n}收敛，则\lim_{n \to \infty} u_{n}=0$
	- 逆否命题成立
	- 逆命题不成立，反例：调和级数
### 正项级数敛散性的判别法

- 正项级数的概念
- 正项级数收敛的充要条件：正项级数的部分和数列$S_{n}$有上界，即存在常数$M,\forall n \in N,都有S_{n} \leq M$
	- 可由该定理推出一系列判断正项级数敛散性的方法
		- 比较判别法
			- 比较判别法的极限形式
		- 比值判别法 / 达朗贝尔判别法
		- 根植判别法 / 柯西判别法
		- 积分判别法
- 负项级数
	- 敛散性和正项级数相同
